DataTables 1.12.1

DataTables CDN files for DataTables 1.12.1. This software was originally released on 19th May, 2022.

Release notes

We've found a few bugs since the 1.12.0 related specifically to the new locale support, which are addressed in this release. There are also a couple of other fixes included - see below for full details.

Fixes:

  • Fix: Bootstrap (3/4/5) integration with table-sm and the sorting icons for 1.12 - icons would overlap
  • Fix: Remove IDs from cloned elements when scrolling is enabled
  • Fix: Don't had a prefix / postfix to the number rendering helper when an empty string or null is used
  • Fix: Error was being thrown when the browser's language was set to a locale which does not use a thousands indicator for 1000.1 when formatted (Polish for example).
  • Fix: IE11 was throwing an error with the new locale rendering for numbers. Default to US English for legacy browsers.
